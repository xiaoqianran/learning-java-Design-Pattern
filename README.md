# Java 设计模式实战学习

交互式中文 **Java 设计模式** 教程：课程 + 测验 + 进度 + 模式沙盘 + 速查表。

结构与体验参考：[learning-vue3](https://github.com/xiaoqianran/learning-vue3)

**仓库：** [https://github.com/xiaoqianran/learning-java-Design-Pattern](https://github.com/xiaoqianran/learning-java-Design-Pattern)

---

## 这是什么

面向想系统掌握 **GoF 设计模式** 与 **SOLID**，并能映射到 **JDK / Spring** 的同学。

你可以：

- 按路径学完课程（讲解 + Java 源码 + 交互沙盘 + 小测验）
- 在 **模式图谱** 里总览 23 种模式
- 在 **模式沙盘** 做场景→模式匹配闯关
- 用 **速查表 / 练习场 / 错题本 / 结业证明** 跟进度

> 本站用 React + TanStack Start 承载教学内容；代码示例为 Java，交互 Demo 在浏览器内模拟模式行为（不嵌入 JVM）。

---

## 学习路径

| 路径 | 内容 |
|------|------|
| **设计基础** | 模式是什么、SOLID、原则、分类、UML |
| **创建型** | 单例、工厂方法、抽象工厂、建造者、原型 |
| **结构型** | 适配器、桥接、组合、装饰、外观、享元、代理 |
| **行为型** | 策略、观察者、命令、模板、迭代器、状态、责任链… |
| **实战** | Spring 映射、组合拳、反模式、电商案例、面试串讲 |
| **速查** | 对比表、选型清单（可选，不阻塞结业） |

## 本地运行

```bash
git clone https://github.com/xiaoqianran/learning-java-Design-Pattern.git
cd learning-java-Design-Pattern
npm install
npm run dev
```

Node 22+ 推荐。

```bash
npm run build        # 生产构建
npm run build:pages  # GitHub Pages
```
